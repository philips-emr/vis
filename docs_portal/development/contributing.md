# Contributing to the project

Contributions to the VIS.js library are very welcome!
It's just extremely important to keep in mind that the more customizations we make, the more work we'll have to do in the event of a library migration.

Currently, the fork from which the VIS copy we used was created has been archived and is no longer maintained.

The VIS library was forked from the github project: https://github.com/almende/vis.git.
